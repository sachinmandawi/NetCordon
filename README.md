### ✨ Highlights

* **Zero Root & Zero VPN** — Direct OS network control via Shizuku ADB binder. No battery drain, and works alongside your real VPN.
* **Smart Shield (Single-Tick ✓)** — Auto-cuts background traffic when an app is closed or screen is locked. Restores instantly when reopened.
* **Total Blackout** — 100% internet drop for chosen apps on Wi-Fi and Mobile data.
* **Distraction-Free Muting** — Blocks background popups, alerts, and vibrations from restricted apps.
* **Floating Speedometer** — Real-time live download/upload speed overlay and leak radar.
* **Biometric Security** — Fingerprint, Face unlock, and PIN/Pattern app lock.
* **In-App Updater** — 1-tap direct update engine without uninstalling.

---

### 📋 Requirements

* Android 8.0 (Oreo) or higher (Android 8 – 15+)
* [Shizuku](https://shizuku.rikka.app/) running via Wireless Debugging or ADB
